# Pizzarella Website

A rustic, Italian-style website for Pizzarella, an authentic pizzeria featuring a red-brownish brick wall aesthetic. This responsive website is designed to showcase the restaurant's authentic Italian atmosphere, menu, and services.

## Features

- Responsive design that works on mobile, tablet, and desktop
- Rustic Italian aesthetics with brick-red color scheme
- Clean, user-friendly navigation
- Sections for:
  - Menu preview
  - Gallery
  - Promotions
  - Location & Contact
  - About Us
